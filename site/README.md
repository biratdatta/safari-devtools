# Website

The static site for Safari DevTools: no build step, no external requests.

## Deploy on Cloudflare Pages (from this repo)

1. Cloudflare dashboard → **Workers & Pages** → **Create** → **Pages** → **Connect to Git**.
2. Pick the `biratdatta/safari-devtools` repo and the `main` branch.
3. Build settings:
   - **Framework preset:** None
   - **Build command:** *(leave empty)*
   - **Build output directory:** `site`
4. **Save and Deploy.** It's live at `https://<project>.pages.dev`; add your own domain under **Custom domains**.

Every push to `main` redeploys the site automatically.

## Keeping it up to date

After changing the tool or the extensions, run `./sync.sh` from the repo root. It copies `safari-devtools.js` into
`site/` and `site/demo/` and rebuilds the two extension zips in `site/downloads/`. Commit and push, and Cloudflare
redeploys.

## Languages

The site is in English (`/`), Simplified Chinese (`/zh/`) and Japanese (`/ja/`). The translated pages are generated
from `index.html` by `i18n/build.py`, which holds the translations. After editing `index.html`, run
`python3 site/i18n/build.py` (or `./sync.sh`). If you changed English text that has a translation, the script stops
and lists what to update. To add a language, add a column to `STRINGS` and an entry to `LANGS` in that file, and a link
in the language menu of `index.html`.

English visitors whose browser prefers Chinese or Japanese see a one-line suggestion to switch (never an automatic
redirect); the choice is remembered.

## Articles, comparisons and guides

The pages under `/compare/`, `/learn/` and `/guides/` (and `/privacy/`) and the big site footer come from
`content/pages.py`. Each page is one entry in `PAGES` (path, title, description, body HTML, related pages, optional
FAQ). The build renders them with structured data (TechArticle, breadcrumbs, FAQ), adds them to `sitemap.xml` and
`llms.txt`, and lists them in the footer of every page. To add an article, add an entry and run `./sync.sh`.

## What's here

```
index.html            the landing page (CSS and JS inline)
zh/, ja/              Chinese and Japanese pages (generated by i18n/build.py)
compare/, learn/, guides/, privacy/   articles (generated from content/pages.py)
assets/               shared CSS for the articles and footer
safari-devtools.js    the tool, for "Try it on this page" and the bookmarklet
demo/                 the live demo shop used by the showcase (the real panel)
downloads/            Chrome and Safari extension zips (rebuilt by ../sync.sh)
media/                demo video and poster
og.jpg, favicon.png   social preview image and icons
_headers, 404.html    Cloudflare Pages headers and not-found page
```
