Safari DevTools vs vConsole

Updated 2026-10-20 · 2 min read

vConsole, from Tencent, is a lightweight console that runs inside the page. It's especially common in WeChat mini-sites and in-app pages. Safari DevTools also runs in the page, with a Chrome-style interface and more debugging tools.

At a glance

vConsoleSafari DevTools
Runs inside the page✓ Yes✓ Yes
LicenceMITMIT
Logs, network list, elements, storage✓ Yes✓ Yes
Source-mapped stack traces✕ No✓ Yes
Edit CSS live✕ No✓ Yes
Mock, block, delay and throttle requests✕ No✓ Yes
Accessibility tools✕ No✓ Yes
Redux / NgRx time travel✕ No✓ Yes
Plugin API✓ YesNo
Size and simplicityVery small and simpleLarger, more complete

Choose vConsole when

You want the smallest possible console inside a WeChat or in-app page, and logs plus a basic network list are enough.

Choose Safari DevTools when

  • You want to fix things in place: edit CSS live, inspect elements through shadow DOM, mock failing APIs.
  • You need errors mapped to your original source.
  • You care about accessibility, Redux state or sharing a bug report with your team.

Both work in in-app WebViews as long as you can load a script into the page. See debugging iOS WebViews.

Try Safari DevToolsFree and open source. Works in Safari, Chrome and on iPhone.
