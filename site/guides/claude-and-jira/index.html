Set up "Explain with Claude" and Jira bug reports

Updated 2026-10-20 · 2 min read

Both features run through the same small relay you use for remote mode. Your keys stay in the relay on your computer; the page and the phone never see them.

Start the relay with your keys

ANTHROPIC_API_KEY=sk-ant-... \
JIRA_URL=https://your-team.atlassian.net \
JIRA_EMAIL=you@company.com \
JIRA_TOKEN=... \
JIRA_PROJECT=WEB \
node standalone/remote/relay.js
  • Set only the Claude variables, or only the Jira ones, if you want just one feature.
  • SDT_MODEL chooses the Claude model; JIRA_ISSUE_TYPE defaults to Bug.
  • Create a Jira API token in your Atlassian account settings under Security → API tokens.

Use them

  • Explain with Claude: click ✨ Explain on any console error. You see the full prompt (the error, the original source around it, recent requests and logs) and can edit it before clicking Ask Claude.
  • Report a bug: click the bug icon in the panel's toolbar. Steps to reproduce, console errors and device info are filled in; tick the HAR, debug report or screenshot to attach, then click Create Jira issue.

Without a relay

You can still use Open in Claude.ai or Copy prompt, and Copy as Jira text or Download attachments.

Security

  • Without a token, the relay only accepts these requests from your own computer and from local pages (localhost, *.local, *.test). Add other development sites with SDT_ORIGINS=https://staging.example.com.
  • For a phone or another machine, start the relay with SDT_TOKEN=... and enter the token in the dialog's relay field.
  • Sign-in codes, tokens, cookies and authorization headers are blanked from prompts, reports and attachments before anything is sent.
