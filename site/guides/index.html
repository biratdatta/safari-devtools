Setup guides

Step-by-step setup for the Chrome and Safari extensions, remote debugging on iPhone, and the Claude and Jira integrations.

Install Safari DevTools in Chrome and EdgeInstall the Safari DevTools extension in Chrome, Edge, Brave or Arc in about a minute, open it with Alt+Shift+D, and fix common problems.Install Safari DevTools in Safari on MacAdd the Safari DevTools extension to Safari as a temporary extension in a minute, or build it once with Xcode to keep it installed. Includes troubleshooting.Remote mode: debug an iPhone from your computer over Wi-FiStream an iPhone page's console and network to your computer and run JavaScript on the phone with a small Node relay. No cable or Xcode; works on Windows.Set up "Explain with Claude" and Jira bug reportsTurn on AI error explanations with Claude and one-click Jira bug reports, using a local relay that keeps your API key and Jira token on your machine.
