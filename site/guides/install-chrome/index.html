Install Safari DevTools in Chrome and Edge

Updated 2026-10-20 · 2 min read

The Chrome extension works in Chrome 111 and later, and in other Chromium browsers such as Edge, Brave and Arc.

Install

  1. Download the Chrome extension and unzip it.
  2. Open chrome://extensions (Edge: edge://extensions) and turn on Developer mode.
  3. Click Load unpacked and choose the safari-devtools-chrome folder.
  4. Pin it from the puzzle-piece menu.

Use it

Open any website and press Alt ⇧ D (⌥ ⇧ D on Mac), or click the icon. On pages whose content sits in a full-window frame, such as CodePen, Storybook or claude.ai artifacts, the panel opens inside that frame.

Troubleshooting

What you seeWhy, and the fix
A red ! on the icon and a help tabChrome refused on that page; the help tab says why. Chrome never allows extensions on its own pages (New Tab, chrome://, the Web Store).
Nothing on a local file:// pageOn chrome://extensions, open the extension’s Details and turn on Allow access to file URLs.
Works on some sites, not othersIn Details → Site access, choose On all sites. Company-managed Chrome may block extensions on some domains; use the bookmarklet there.
Old behaviour after an updateClick the reload ↻ arrow on the extension card, then reload the page.

To change the shortcut, open chrome://extensions/shortcuts.
