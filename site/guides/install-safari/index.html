Install Safari DevTools in Safari on Mac

Updated 2026-10-20 · 2 min read

There are two ways to add the extension to Safari: a quick temporary install, or a one-time Xcode build that stays installed.

Quick: temporary extension

  1. Download the Safari extension and unzip it.
  2. In Safari, open Settings → Advanced and turn on Show features for web developers.
  3. Open Settings → Developer, click Add Temporary Extension… and choose the safari-devtools-extension folder.
  4. In Settings → Extensions, turn on Safari DevTools and allow it on websites.

Temporary extensions are removed when Safari quits; add it again next time.

Permanent: build with Xcode

  1. Install Xcode from the Mac App Store and open it once.
  2. In Terminal, inside the extension folder, run ./build-xcode-project.sh (add --ios to build for iPhone and iPad too).
  3. In Xcode, pick your Team under Signing & Capabilities for each target (a free Personal Team works), then press ⌘ R.
  4. Turn the extension on in Safari → Settings → Extensions and allow it on every website.

Use it

Press Ctrl ⇧ D on any page, or click the toolbar button.

Troubleshooting

  • Not listed in Settings: run the app from Xcode again and restart Safari.
  • Disappears after quitting Safari: it was added as a temporary or unsigned extension. Pick a Team in Xcode so it stays.
  • Does nothing on a page: allow it for that site from the toolbar icon. Safari's own pages never allow extensions.
