How to see console logs on iPhone without a Mac

Updated 2026-10-20 · 2 min read

Apple's Web Inspector needs a Mac. If you don't have one, or don't have it with you, you can still read the console straight from the page.

Option 1: a bookmarklet (any website, no install)

  1. On the install section, open the Bookmarklet tab and copy the code.
  2. In Safari on the iPhone, bookmark any page, then edit that bookmark and paste the code as its address.
  3. Open the page you want to debug and tap the bookmark. The panel opens at the bottom of the screen.

It loads after the page, so messages logged before you tap aren't captured. Tap it, then reload the page if you need everything from the start.

Option 2: a script tag (your own site)

Add this as the first thing in <head> of your development build. It captures every log and request from the first line:

<script src="https://cdn.jsdelivr.net/gh/biratdatta/safari-devtools@v1.5.2/standalone/safari-devtools.js"></script>

A round button appears in the corner of the page. Tap it to open the console.

Option 3: remote mode (watch from any computer)

Reading logs on a phone screen is fiddly. Remote mode streams the phone's console and network to your computer over Wi-Fi, and lets you type JavaScript that runs on the phone. It works from macOS, Windows or Linux.

git clone https://github.com/biratdatta/safari-devtools
cd safari-devtools
node standalone/remote/relay.js

Then open http://<your-computer-ip>:9230/demo on the iPhone, and http://localhost:9230 on the computer. The remote mode guide covers using it with your own pages.

HTTPS pages: Safari won't let an https:// page talk to an http:// relay. Use remote mode with your local http:// dev server, or serve the relay over HTTPS.

If you do have a Mac

Safari's Web Inspector gives you breakpoints and profiling too. See Safari DevTools vs Web Inspector for when each is the better choice.

Questions

Can I see iPhone Safari console logs on Windows?

Yes. Load Safari DevTools on the page to see the console on the phone, or run its relay with Node on your Windows PC and watch the phone's console in your browser.

Do I need to jailbreak or install an app?

No. Safari DevTools runs inside the web page, so it works in the normal Safari app.
